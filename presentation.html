踩坑合集

⚠ CLI 被误删
Claude Code CLI 被误删了
npm install -g @anthropic-ai/claude-code
⚠ Chrome 崩溃
"并行配置不正确" 无法启动
重装 VC++ 运行库
⚠ 更新中断
Chrome 更新后打不开
用 new_chrome.exe 替换旧 exe
⚠ 扩展连不上
桥接扩展无法连接守护进程
手动点击 "Start Serving"
⚠ GitHub 连不上
网络无法访问 GitHub
配置 HTTP_PROXY 代理
